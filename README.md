# Katende Philbert — Professional Portfolio

Live website: https://philbertkatende.github.io/

A responsive, accessible, static professional portfolio for Katende Philbert, a Ugandan B.Pharm graduate and Pharmaceutical Society of Uganda member.

## Sections

- Professional introduction and biography
- Hospital pharmacy and pharmaceutical quality experience
- Skills and pharmacy calculation / medicine-safety tools
- Projects and digital learning
- Research and publication record
- Education, training and leadership
- Contact information

## Research publication

Ogwang PE, Joshua K, Katende P, et al. **Prenatal Developmental Toxicity of ARVIDEX® Herbal Medicine in Albino Wistar Rats.** *Cureus*. 2026;18(2):e103279. https://doi.org/10.7759/cureus.103279

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Local preview

Open `index.html` in a browser, or serve this folder with any static-file server.

## Deployment

The repository is configured as a GitHub Pages user site. Changes pushed to the `main` branch are published by GitHub Pages.

## Content integrity

Professional experience, dates, research authorship and claims should be kept aligned with verifiable records. The pharmacy tools are educational aids and must not replace clinical references, patient-specific assessment or local guidelines.
